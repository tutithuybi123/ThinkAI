# Evidence-bounded research gaps

- **A:** conditional gap: taxonomy-held-out selective ranking measured by safe accepted-set error versus non-generative retrieve–rerank; not a new RAG/reranking method.
- **B:** no retained gap: broad hybrid accessibility auditing is already evaluated and lacks recovered benchmark ground truth.
- **C:** conditional gap: Vietnamese claim-level evidence attribution with OOD/noisy-context calibration, only after data structure is verified.
- **D:** no current gap because AQ-SPEC+AQS data pairing fails. A later paired dataset could support an incremental pre-registered transfer/coverage evaluation, not a generic calibration claim.

## Gate-controlled claims

**A:** the only potential contribution is an evaluation result: a fixed taxonomy-/construct-held-out protocol testing whether a selective ranking policy reduces high-confidence wrong diagnoses at matched coverage. It fails if a dense retrieve–rerank baseline has equal/better risk–coverage, if the split leaks templates/labels, or if a direct 2023–26 task-specific study already reports the same protocol. RAG, hierarchy, reranking, conformal prediction, confidence calibration, and abstention are excluded as standalone novelty claims.

**D:** site/device-held-out calibration, transfer, drift, uncertainty intervals, and abstention are established directions. With no verified paired AQ-SPEC dataset, no research-gap claim can be tested. A later raw lawful collocation source could at most reopen a blocked-split robustness evaluation; it would not make XGBoost, transfer learning, or conformal prediction novel.
