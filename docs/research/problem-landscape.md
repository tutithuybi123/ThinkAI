# Problem landscape — evidence-first discovery

Status: research synthesis, not a product decision. “AI role” is a hypothesis; it is not evidence that AI improves outcomes.

## Interpretation

The strongest signals do not establish a single project. The following is an **inference**: a candidate should name a narrow user, a difficult-to-automate mechanism, an objective outcome, and a privacy-respecting data path. Generic tutoring, clinical mental-health assessment, and broad “AI for accessibility” claims fail this initial desk-research test unless sharply reframed.
