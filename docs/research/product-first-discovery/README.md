# Product-first discovery — broad problem atlas

Status: **Stage A complete; checkpoint for human review.** This folder deliberately records real workflows before choosing a project, model, or shortlist. It supersedes neither the earlier research folders nor their conclusions; those materials are context only.

The atlas and rolling-wave appendix contain **187 distinct concrete problems across 31 domains**. The canonical CSV holds the first 125 normalized rows; the appendix preserves 62 additional gap-targeted, deduplicated source-led records. Entries labelled `SOURCE-EVIDENCED` have a cited source supporting the underlying pain/workflow. A small number labelled `MIXED` use a documented pain signal plus a clearly marked researcher inference to make the workflow operationally specific. No entry is evidence that an AI solution works or is needed.
