# Rejected directions

| Direction | Gate failed | Reason |
|---|---|---|
| AI-writing/cheating detector | Fairness, ground truth, differentiation | Even Turnitin says false positives remain and its indicator does not determine misconduct; detection invites accusation rather than learning evidence ([Turnitin](https://www.turnitin.com/blog/understanding-false-positives-within-our-ai-writing-detection-capabilities)). |
| Generic source/citation checker | Novelty | Browser/search and numerous academic tools already retrieve/cross-check citations; differentiation would be UI/orchestration. |
| General misinformation detector | Ground truth, safety | Open-world truth changes with time/context; false confidence is dangerous. |
| Deepfake detector | Arms race, model availability | Commodity APIs/research are extensive, generalization degrades with new generators, and provenance is a better complement. |
| Accessibility converter | Ground truth/setup | Important, but previous repository validation found expert ground truth and lawful Vietnamese corpora unresolved; no fundamentally new problem emerged. |
| Home/corridor hazard detector | Safety/setup | Real need, but reliable scene coverage and liability require extensive local capture/expert labeling; rules/checklists solve common cases. |
| Environmental/crop/defect vision | Novelty/data | Heavily explored; local image labels and specialist access dominate feasibility. |
| Flood prediction/map | Non-AI/model-data | Sensors, hydrology and geospatial models—not a student-scale GenAI system—supply the core value. |
| Disaster message summarizer | Differentiation | CrisisFACTS already defines temporal summarization; summarization alone does not establish truth or safe action. |
| Generic lab-report feedback/writer | Novelty/problem | Normal rubric feedback and LLM writing assistance are common. B survives only by constraining claims to the student's captured evidence. |
| AI-use disclosure ledger | Adoption/non-AI | Forms/version history can record use; policing compliance is weak and overlaps Candidate A. |
| Communication/pronunciation coach | Prior-art | Eliminated in the preceding deep validation: mature competitors cover most of the loop. |

These rejections are discovery judgments, not assertions that the underlying social problems are unimportant.
