# Kill criteria assessment

| Criterion | Finding | Consequence |
|---|---|---|
| Existing products deliver same loop | **Met for broad concept.** Yoodli is very close; VirtualSpeech/Ovation/ELSA/Duolingo cover major pieces. | Kill broad multi-world sandbox. |
| Frontier models reduce work to UI wiring | **Met unless evidence ledger beats baseline.** | Reframe only around verifiable method, not roleplay. |
| Required language prosody inaccessible | **Met for Vietnamese scoring.** | Exclude Vietnamese pronunciation/prosody grade. |
| No quantitative evaluation | **Not met yet, but unexecuted.** | Run small technical reality check before proceeding. |
| Product too broad | **Met.** | One world only. |
| Subjective LLM scoring dominates | **Would be met** for debate/confidence/persuasion. | Prohibit those scores. |
| Privacy impractical | Not necessarily; minors add material controls. | Default no retention and consent controls. |
| Demo only works on easy cases | Unresolved. | Require failures/held-out benchmark. |
| Competition differentiation weak | **Met for generic loop.** | Establish teacher-specific transparent evidence contribution. |
| Non-AI suffices | Partly: stopwatch/script/peer cover basics. | AI must justify only on-demand interaction + scalable evidence linkage. |

The broad candidate fails multiple kill criteria. The narrow reframing survives only conditionally: it must outperform raw transcript/edit distance and generic LLM feedback in transparent, teacher-rated usefulness.
