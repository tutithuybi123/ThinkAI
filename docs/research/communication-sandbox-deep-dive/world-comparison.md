The sandbox should not ship as multiple worlds. Two worlds would obscure the evidence boundary and create an impressive but undefensible demo. If later validated, a single Vietnamese presentation/script rehearsal world could prove a reusable contract; English is a comparator, not an equal first-world. Debate should be a future exploratory module only after a fixed rubric and human-rated evidence exist.
