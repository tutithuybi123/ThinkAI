# Contribution / novelty attack

| Element | Classification | Attack |
|---|---|---|
| Realtime voice roleplay | Commodity | Realtime APIs, Duolingo, Yoodli and ELSA already supply it |
| ASR plus filler/rate dashboard | Commodity | Orai, Poised, Yoodli and VirtualSpeech supply variants |
| LLM summary/feedback | Commodity | Normal API orchestration is not novel |
| Separate simulator/evaluator | System engineering | Useful for testability; not novel alone |
| Evidence ledger separating fact from suggestion | Potential differentiation | Only meaningful if user-facing, accurate, and benchmarked |
| Teacher-scoped Vietnamese rehearsal contract + adaptive retry | Potential local product contribution | Must show a measurable teacher/user advantage |
| New consented benchmark and human-rater protocol | Potential research contribution | Strong only if lawful, transparent, and actually executed |
| “AI detects confidence/debate quality” | Unsupported | Avoid as a contribution |

The defensible contribution is not model training nor API wiring. It is an evaluation methodology and UX contract: every claim links to an observable span/metric, uncertain semantic feedback is marked as such, and a retry comparison prevents opaque holistic scoring. Novelty is **unproven** until it beats a generic baseline on helpfulness and evidence accuracy.
