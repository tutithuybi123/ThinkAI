# Responsible AI

| Risk | Safeguard |
|---|---|
| Accent/cultural bias | Do not use “native-like” or a universal ideal; evaluate intelligibility/correctness separately from preference; test regional/accent slices and provide appeal/ignore controls. |
| Inaccurate pronunciation/prosody feedback | English assistive scope only with validated benchmark; exclude Vietnamese score; evidence spans, uncertainty and abstention. |
| Subjective LLM judgement | Do not grade confidence, charisma, persuasion, truth/fallacies; use a teacher-defined rubric and tentative suggestions with cited transcript evidence. |
| ASR contamination | Display transcript confidence; user correction; do not penalize uncertain tokens; retain raw/edited distinction. |
| Minor voice privacy | Default no retention; explicit guardian/school consent where needed; minimised data, encrypted transport/storage, deletion control, no training/reuse without explicit lawful permission. Use synthetic/public data for tests. |
| Generated roleplay harm | Age-appropriate scenario templates, policy filter, report/stop controls, no adversarial/political persuasion targeting. |
| Dependency/anxiety | Frame as rehearsal aid, recommend teacher/peer feedback for high-stakes tasks, avoid punitive streaks/rankings. |
| Overconfidence/vendor drift | Version/prompt ledger, monitoring, fallbacks, feature flags and clear “AI suggestion” disclosure. |

The product must say what it measures, how, and what it cannot infer. “Correctness” concerns a supplied script/rubric; “comprehensibility” should involve appropriate human validation; “style” is a learner choice, not a defect.
