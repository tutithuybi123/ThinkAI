## 90% test

A learner can already combine Yoodli (roleplay/presentation feedback), ELSA or Microsoft (English pronunciation), and a realtime model (conversation) for most proposed value. The project must therefore not exist merely as a new interface for those capabilities. A residual gap is only credible if it demonstrates that a Vietnamese school-specific evidence ledger and retry comparison is more transparent/useful than generic feedback and is validated by teachers.
