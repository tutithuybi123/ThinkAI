# AI Communication Practice Sandbox — deep validation

**Status: adversarial research; no MVP selected.** This dossier tests the candidate against evidence, current products, capability limits, and the competition criteria supplied in the task brief. It is not a claim that the worktree contains an official Bảng B rulebook: no such document was found locally. Sources are traceable in [source-table.csv](source-table.csv); vendor claims are labelled as such.

## Bottom line

The human need is real, strongest for repeated, low-stakes **targeted L2 speaking/pronunciation practice with feedback**. The broad sandbox is not defensible: Yoodli, VirtualSpeech/Ovation, ELSA, Duolingo and realtime models already cover most of simulation, basic analytics, and English practice. A general presentation/debate “quality score,” especially for Vietnamese, would be overclaiming.

The only credible survivor is a **reframed Vietnamese secondary-school presentation/script rehearsal evidence loop**: practice a teacher-provided prompt or script; show transcription-linked omissions, insertions, repetitions, fillers, timing and pauses; label semantic/argument suggestions as tentative; retry and compare only stable facts. Vietnamese automatic pronunciation/prosody scoring is excluded pending human-rated validation. This may be a useful competition direction, but it has not passed a technical reality check against a baseline.

## Evidence rules

* **Fact/evidence** has a source; **inference** is marked; **unsupported** means the review did not establish it.
* A measurement is not automatically a quality judgment. A pitch range or words/minute needs context.
* A product page establishes a feature claim, not efficacy, accuracy or fairness.
* No personal or child voice data were collected. No external API/model calls were represented as tests.
