# Product forms compared

| Form | Initial user/use moment | Core loop | AI-specific value | Objective proof | 3-minute demo | Verdict |
|---|---|---|---|---|---|---|
| Conventional adaptive app | THPT learner practicing a math unit | assess → lesson → practice → mastery map | Interpret free reasoning and generate variants | held-out task, transfer and delayed accuracy | diagnosis/path/quiz | Too ordinary as the main identity |
| Challenge-based ThinkAI | THPT learner after AI-assisted homework | assisted challenge → fade help → independence trial → delayed return | Generate controlled variants and adapt scaffolds to reasoning | unaided near-transfer, help reduction, retention | same learner “succeeds” with AI then fails/passes new challenge | **Best form** |
| AI companion | Self-learner across resources/weeks | observe → remember → intervene | Cross-context synthesis and long memory | hard attribution; privacy-heavy | mostly chat/history | Reject for first product |
| Diagnostic + intervention engine | Learner stuck on bounded math skill | elicit reasoning → test hypotheses → select intervention → verify | Understand varied reasoning and create discriminating tasks | diagnosis calibration plus transfer gain | two similar errors receive different tests | Strong alternative engine, weak standalone habit |
| Teacher-connected system | Teacher between lessons | teacher goal → individual practice → evidence report | Scale tailored elicitation and practice | teacher labels, classroom test, reduced review time | class of three learners, one evidence trail | **Best deployment wrapper** |
| Learning operating system | Learner across YouTube/books/chat | ingest everything → maintain global state → orchestrate resources | Cross-resource understanding | nearly impossible in MVP | complex dashboard | Kill: scope/privacy/integration |
| Transfer Quest game | Competitive/strong THPT math learner | mission → learn tool → new-world application → boss transfer test | Generate diverse isomorphic contexts and responsive characters | solution correctness and transfer across representations | principle learned in one world unlocks another | High-risk, memorable |

## Chat's role

Chat should be a secondary input method, not the product shell. It is useful for eliciting reasoning and delivering a small Socratic cue. The primary interface should show a challenge, the learner's work, the assistance state, and the next proof. A blank chat box recreates the frontier-tutor baseline and invites answer-seeking.

## Game mechanics that could improve learning

Only three mechanics survive:

* **Locked tools:** a learned principle becomes a tool only after independent proof; this makes mastery consequential.
* **Context shifts:** the same underlying relation appears in a new representation/world, making transfer the play mechanic.
* **Boss return:** a previously learned skill reappears after spacing with no hints, turning retention into progression.

Points, streaks, avatars and leaderboards add no learning mechanism and should not define ThinkAI. Competitive ranking could punish slower learners and distort help-seeking.
