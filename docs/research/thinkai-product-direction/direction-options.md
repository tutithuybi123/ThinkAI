# Serious product directions

## Direction 1 — Proof-of-Learning Challenge System

**Problem:** Learners and teachers cannot tell whether a polished AI-assisted solution represents durable independent ability.

**User:** Initially THPT mathematics learners who already use AI for homework or exam preparation, with a teacher/mentor able to validate task scope.

**Loop:** Attempt unaided → request metered help → complete → solve a structurally related problem without AI → revisit later → update evidence.

**Signature:** “Assisted success” and “independent proof” are visually separate states. ThinkAI does not shame assistance; it shows what assistance enabled and what remained.

**Why frontier chat is insufficient:** A prompt can ask ChatGPT for a quiz, but cannot reliably maintain an auditable assistance ledger across providers, schedule delayed probes, compare transfer distance, or prevent the evaluation from seeing the tutoring transcript/answer.

**Kill test:** If a frontier tutor plus a simple scheduled quiz produces equivalent independent-transfer gains and evidence clarity, ThinkAI is unnecessary.

## Direction 2 — Teacher-Connected Intervention Lab

**Problem:** The same wrong answer can arise from different reasoning, and teachers cannot individually test competing explanations/interventions at scale.

**User:** A math teacher managing students with recurring errors in one bounded unit.

**Loop:** Collect answer/reasoning → propose uncertain hypotheses → ask the smallest discriminating question → choose a teacher-approved intervention → verify on new task → report evidence.

**Signature:** ThinkAI must disprove its own diagnosis. “Not tested” is a first-class state, and the next question is selected for information value rather than content coverage.

**Why frontier chat is insufficient:** It requires a persistent teacher-defined misconception/rubric boundary, controlled hypothesis tests, calibrated abstention, and outcome comparison—not merely plausible diagnosis. The repository's existing oracle-25 test found a strong model only 67.3% accurate with many high-confidence errors, strongly arguing against direct LLM labels.

**Kill test:** If deterministic error rules/static teacher hints match learning outcomes, AI is unnecessary.

## Direction 3 — Transfer Quest (high risk)

**Problem:** School practice often rewards recognizing a familiar exercise template rather than noticing when a principle applies in a different situation.

**User:** Motivated THPT math/physics learners, especially clubs or competition-oriented students.

**Loop:** Encounter a mission → invent/predict → earn a mathematical tool with scaffolding → apply it in a changed representation/context → later boss encounter without help.

**Signature:** The world changes but the principle survives. Progress is based on transfer, not task count.

**AI necessity:** AI can respond to unconventional strategies, generate diverse but constraint-checked scenarios, and adapt hints while a symbolic/test harness verifies answers.

**Risks:** content authoring and constraint verification are hard; story can add extraneous cognitive load; motivated niche; generation errors can break trust. This is not the first build unless a paper prototype shows learners want to return.

## Direction 4 — Independence Layer across existing AI tools

**Problem:** Students learn across ChatGPT, Gemini, videos and textbooks; no single tutor sees the difference between assisted work and independent capability.

**Idea:** A provider-agnostic “proof layer” accepts declared/imported assisted sessions, extracts skill hypotheses, then conducts isolated verification.

**Verdict:** strategically interesting but not first. Cross-provider capture, privacy, provenance and gaming make it operationally heavy. It could become the long-term form of Direction 1 after the core learning effect is proven.
