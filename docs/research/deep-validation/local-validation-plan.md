# Local validation plan — no interviews have been conducted

## Environmental QA

Ask science/facilities stakeholders: when was a sensor reading distrusted; how was it checked; which decision depended on it; cost of false/missed alarms; is a reference monitor available?

## Provenance

Ask parents/staff: last conflicting/unclear notice; original source; confirmation path; frequency; concrete consequence. Do not ask “would you use an app?”

## Accessibility

Ask disabled learners, teachers, or accessibility support: last inaccessible material; specific barrier; workaround/time cost; what a screen reader/user got wrong; who can assess an improved version?

## Misconceptions

Ask teachers/students: last recurring misconception; evidence they use; current hint/workaround; what makes a hint harmful/helpful; whether a delayed follow-up exercise is feasible.

## Route exposure

Ask families/school staff: route choices; last air/traffic concern; existing information used; whether location data is acceptable; what non-location evidence could support a decision. No continuous tracking request.
