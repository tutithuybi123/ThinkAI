# Ubuntu competition release

Copy `.env.production.example` to `.env.production`, install the approved teacher-reviewed content/seed files at the configured secret paths, set `CLOUDFLARE_TUNNEL_TOKEN` on the host, then run `tools/deploy/deploy-debian.ps1`. The default Compose file runs the Cloudflare Named Tunnel; `docker-compose.named-tunnel.yml` remains a compatible no-op override for existing deployment commands. Cloudflare Tunnel is the only public ingress; neither app nor PostgreSQL publishes host ports. Verify `docker compose ps`, `/healthz`, migrations, and the authenticated learner/Ops flow after every update. The target is a generic Linux Docker host; no Ubuntu package-management assumption is required.
