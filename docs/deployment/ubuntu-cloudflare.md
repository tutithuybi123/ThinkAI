# Ubuntu competition release

Copy `.env.production.example` to `.env.production`, install the approved teacher-reviewed content/seed files at the configured secret paths, then run `tools/deploy/deploy-debian.ps1`. The default Compose file uses a TryCloudflare Quick Tunnel; use `docker compose -f docker-compose.yml -f docker-compose.named-tunnel.yml up -d` once a named tunnel/domain token is available. Cloudflare Tunnel is the only public ingress; neither app nor PostgreSQL publishes host ports. Verify `docker compose ps`, `/healthz`, migrations, and the authenticated learner/Ops flow after every update. The target is a generic Linux Docker host; no Ubuntu package-management assumption is required.
