# Wireframe text — màn hình P0

Ví dụ layout, không phải final visual. `[quan hệ X]` là dữ liệu content đã được duyệt.

## A. Bài luyện

```text
┌──────────────────────────────────────────────────────────────────────────────────────────────┐
│ ← Học / [Kỹ năng]                                   BÀI LUYỆN                 [Lưu và thoát] │
├───────────────────────────────────────┬──────────────────────────────────────────────────────┤
│ ĐỀ BÀI                                │ BÀI LÀM CỦA BẠN                                      │
│ [Dùng quan hệ X để ...]               │                                                      │
│                                       │ Đáp án                                               │
│ ┌───────────────────────────────────┐ │ ┌──────────────────────────────────────────────────┐ │
│ │ đồ thị / bảng / hình Toán         │ │ │                                                    │ │
│ └───────────────────────────────────┘ │ └──────────────────────────────────────────────────┘ │
│                                       │ Cách làm (không bắt buộc)                            │
│ [Xem gợi ý]                          │ ┌──────────────────────────────────────────────────┐ │
│                                       │ │                                                    │ │
│ ┌ Gợi ý để bắt đầu ────────────────┐ │ └──────────────────────────────────────────────────┘ │
│ │ Nhìn vào ...                      │ │ [Chưa biết bắt đầu]                 [Gửi bài]      │
│ │ Gợi ý không làm giảm tiến độ.     │ │                                                      │
│ └───────────────────────────────────┘ │                                                      │
└───────────────────────────────────────┴──────────────────────────────────────────────────────┘
```

## B. Cầu nối sau khi giải

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│  ✓  Bạn đã giải được bài này.                                                 │
│     Bạn đã xem gợi ý về [chiến lược] — đó là một cách học hợp lệ.            │
│                                                                             │
│  ┌───────────────────────────────────────────────────────────────────────┐  │
│  │  Dùng cùng ý tưởng ở một dạng mới                                    │  │
│  │  Bài tiếp theo trông khác. Hãy thử xem [quan hệ X] còn dùng được không.│  │
│  │                                      [Xem lại bài] [Thử vận dụng]     │  │
│  └───────────────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────────────┘
```
