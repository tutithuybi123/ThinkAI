# Independence Trial review

## Verdict

At present it is **good UX naming for an ordinary assessment step**, not yet a product signature. It can become a signature only when task construction and the feedback consequence make it recognizably more meaningful than “one more problem without hints.”

## Minimum validity specification

An Independence Trial should have all of the following:

1. An unseen item from a pre-specified family; no reuse of wording, values, solution ordering, or worked-example artifacts.
2. The same target relation/strategy, with one declared shift (representation, context, givens, or solution route), and no unintended prerequisite.
3. A no-help policy that is technical, not merely a request to the learner: no earlier answer in context; no reveal button; separately versioned task session.
4. Teacher review of the item pair and rubric before use; symbolic/answer verification where applicable.
5. A defined result: correct answer plus required explanation/method, response time only as secondary context.

“Harder” is not “transfer.” Nor is changed numbers. Near transfer must be operationalized for **one micro-skill** before implementation.

## Generation, dose, and timing

LLMs may generate candidates, but reliable valid trials need a curated graph/bank. A curated bank can solve the MVP without AI; that is a feature, not a weakness. A single pass is a noisy observation. Do not trigger after every interaction: use one capstone after a bounded learning episode, then one delayed return selected by a declared policy. Repeated trials become annoying when their informational value is low.

## Kill tests

Kill or reframe the signature if (a) teacher reviewers cannot agree item pairs measure the same target with altered surface/representation, (b) a prompt-generated quiz produces equivalent held-out outcomes and perceived value, (c) learners describe it primarily as “extra homework,” or (d) it adds no decision beyond correctness on a fresh problem.

## Better framing

Call the user action **“Use the tool in a new situation”**; reserve “Independence Trial” for the internal protocol/teacher explanation. After the response, reveal the shared relation and issue a capability receipt. This makes transfer—not no-hints discipline—the visible mechanic.
