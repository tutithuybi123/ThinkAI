| Expected category | Fit | Red-team weakness |
|---|---:|---|
| practical problem/target user | medium-high | Vietnamese learner pain and willingness to accept friction untested |

The project is strong competition material if presented as a falsifiable, working evidence workflow with honest validation status. It is weak if presented as a grand learning-science platform without longitudinal data. It is somewhat research-heavy; the demo must foreground a learner’s tangible new-situation challenge, then show the evidence machinery briefly.

## Responsible AI requirements before a pilot

* collect only task events required for the study; no chain-of-thought requirement or psychological profile;
* separate real consented data from synthetic demo data and state which is shown;
* define retention/deletion, access roles, and model/API data handling;
* never punish hints, reduce rank, or promise badges based on help avoidance;
* use neutral recoverable failure language; avoid false mastery, false misconception, and ability labels;
* let a teacher or study lead correct task/error interpretations; record the correction;
* prevent pressure to cheat the protocol by making help a legitimate route and treating independent proof as a later, separate condition.
