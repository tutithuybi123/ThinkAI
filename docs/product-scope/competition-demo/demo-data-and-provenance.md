# Demo data and provenance

> **Status: Historical v1.0 data/provenance scope.** Its privacy/evidence principles remain useful, but v1.1 assistance and conversation provenance are governed by current amendment contracts.

| Data class | Use | Disclosure |
|---|---|---|
| LIVE | current learner events, deterministic score, receipt after current transfer, live AI feedback | current-session timestamp/provider label |
| PRE-AUTHORED / REVIEWED | task pairs, interventions, rubric, mapping | reviewer/version/provenance in audit |
| SEEDED DEMO DATA | clean synthetic account/bootstrap | visibly synthetic/demo where audit exposes it |
| HISTORICAL DEMONSTRATION DATA | delayed/history event only | labelled historical seed/date; never claimed live |

No raw child data, chain-of-thought, credentials or hidden provider prompts belong in UI, source control or normal prompt logs.
