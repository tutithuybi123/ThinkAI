# Demo content requirements

> **Status: Historical v1.0 content requirements.** Use current v1.1 source-of-truth for lifecycle, published pair bank, written solutions and rubric contracts.

Human dependency: a Grade-10 mathematics teacher/content reviewer must choose one atomic, objectively scoreable micro-skill and sign off content provenance. **Absolute Demo execution minimum:** one valid reviewed practice/transfer pair and three reviewed practice interventions for that pair. **Credibility target:** approximately 6–10 valid reviewed pairs where feasible; this target must not be presented as already achieved or as permission to use an invalid pair.

Each active pair needs: skill/task-family/pair versions; approved review record/reviewer/date/notes; declared changed representation/context/givens/route; exact practice and unseen transfer tasks; deterministic answer spec; three intervention IDs/text/versions/exposure tags; authored connection mapping; provenance and validation version. Different numbers or difficulty alone are invalid transfer. No current repository fixture meets this educational-content requirement.
