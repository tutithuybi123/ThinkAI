# Exact 3-minute demo and demo-data strategy

> **Status: Historical presentation planning.** Use only as provenance; current v1.1 learner/product behavior is governed by current authority.

## Story, not feature tour

| Segment | Must show live | May be seeded | Must not show |
|---|---|---|---|
| 0:00–0:20: reason | two equal correct answers with distinct concrete exposure conditions | second learner comparison card | competitor table, theory lecture |
| 0:20–1:05: learn | attempt → reviewed fixed hint → solve; exposure event | initial Home state | numeric AI-help meter |
| 1:05–1:55: signature | isolated changed-representation task and learner response | reviewed pair metadata | prior solution/context in challenge |
| 1:55–2:20: reveal | relation connection and Receipt generated from live events | capability map presentation | mastery percentage or permanent claim |
| 2:20–2:40: time | no live retention claim | clearly labelled historical delayed event with date/time | pretending minutes equal delay |
| 2:40–3:00: credibility | compact audit expansion | pre-seeded learner history | full teacher dashboard, architecture tour |

## Data categories

| Category | Contents | Rule |
|---|---|---|
| LIVE | current attempt, opened hint, submitted answers, resulting receipt/event | visibly created in this demo interaction |
| PRE-AUTHORED / VERIFIED | item pairs, solutions, rubrics, pair metadata, help text | source/version/reviewer available in audit |
| HISTORICAL | one previous delayed-return event with timestamp | labelled historical, never presented as live retention |
| SYNTHETIC DEMO ACCOUNT | learner name/profile, prior receipt/history/current goal | label as demo/synthetic where audit context requires |

## Demo resilience target

The critical path must not need live task generation, live transfer validation, or a live database migration. Prevalidated content, deterministic scoring/state transitions, a resettable demo account, and a defined error/retry state are required. If live AI is used for feedback, disclose it and provide an honest fallback: “AI feedback temporarily unavailable; continue with the reviewed hint and deterministic challenge.” Never pass fixed text off as live AI.
