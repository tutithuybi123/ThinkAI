# Final recommendation

> **Status: Historical planning recommendation.** It does not override current v1.1 source-of-truth or final execution plan.

## Answers required for the decision

1. **Competition MVP:** one complete challenge-first micro-skill application with reviewed help, isolated changed-representation verification, receipt, event history, and compact audit.
2. **Learner actions:** attempt/cannot-start, use help, solve, independently apply in a new situation, receive receipt, view progress/history.
3. **Journey:** defined in [student-journey.md](student-journey.md); it is one flow, not a dashboard tour.
4. **Signature:** apply the same mathematical tool in a visibly different representation, then receive a condition-aware receipt.
5. **Difference from ordinary tutor:** controlled help provenance + reviewed isolated pair + durable evidence + receipt; not better chat.
6. **Production-quality screens:** Home, challenge, Transfer Quest, receipt, history/progress, compact audit.
7. **ACTIVE:** one skill, reviewed pairs/hints, challenge/transfer/receipt/events/history/audit, labelled historical return.
8. **LOCKED:** at most 2–3 adjacent future nodes after active flow is real.
9. **HIDDEN:** subjects, broad paths, teacher LMS, diagnosis, learning layer, general chat.
10. **REMOVE:** XP/coins/leaderboard/streaks/help penalties and numerical help/mastery scores.
11. **Game layer:** capability node + Transfer Quest + Memory Return only.
12. **Receipt:** a compact claim of what was demonstrated, conditions, and unknowns—not an achievement score.
13. **Transfer challenge:** reviewed, unseen, isolated same-target pair with declared meaningful change.
14. **Live AI:** optional bounded explanation/feedback or reviewed-hint selection; it must not block the demo.
15. **Deterministic:** content selection, isolation, scoring where possible, evidence, receipt, state/reset/audit.
16. **Pre-authored data:** pairs, hints, rubrics, solutions, metadata.
17. **Seeded/historical:** demo learner history and explicitly timestamped delayed event.
18. **Show live:** attempt, legitimate hint, solve, isolated transfer response, connection reveal, receipt/update.
19. **Do not show:** broad roadmap, competitor research, full dashboard/LMS, fake retention, decorative game systems.
20. **Current repository:** no implemented application; only planning/research/tooling/templates.
21. **P0 blockers:** valid reviewed pair bank, event/persistence model, scorer, isolation, receipt, reset/fallback.
22. **P1 gaps:** shell/history/audit/states/responsiveness/tests.
23. **High uncertainty:** content validity, live-AI reliability, student desirability, official Bảng B provenance.
24. **Whole-demo blocker:** a valid teacher-reviewed changed-representation pair.
25. **First work:** Phase 0 product/content/event freeze.
26. **After vertical slice:** reliability then shell/polish; not additional learning features.
27. **Core stable:** every P0 flow passes from reset and receipt derives from actual events.
28. **Shell stable:** all visible routes/controls/states are intentional and history is real.
29. **Demo-ready:** repeatable story, honest fallback/data labels, inspectable receipt, no fake claims.
30. **Cut now:** generic tutor, broad content, game economy, automated diagnosis, full teacher product.
31. **Feels real:** coherent shell around a genuinely working evidence loop—not more feature count.
32. **Why not ChatGPT + quiz?:** only if the demo visibly shows the controlled/auditable residue; otherwise it does not answer the question.

## Verdict from actual repository state

**CUT SCOPE.** The direction is coherent enough to build; the repository has no product implementation, so defining an expansive MVP would guarantee a research-demo mismatch. Do not reframe unless the required reviewed pair bank cannot be validated or the controlled evidence loop cannot be made visibly meaningful.

## Competition fit

The proposed slice can demonstrate a practical user/problem, data provenance, meaningful but bounded AI use, deterministic output verification, architecture, testing plan, responsible AI, and modifiability. It cannot honestly demonstrate learning gain yet. Exact Bảng B mapping remains **UNKNOWN** until the actual official source is located and recorded.
