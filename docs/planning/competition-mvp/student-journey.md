# One coherent student journey and signature experience

> **Status: Historical v1.0 journey planning.** Do not use it as current learner-flow authority; see `../../CURRENT.md`.

## The journey

| Step | Student sees/does | System records | AI responsibility | Deterministic responsibility | Feedback and failure path |
|---|---|---|---|---|---|
| Enter | Home: “Continue: use relation X across representations.” Opens challenge. | demo learner/current skill | none required | loads progress/events | clear goal; no empty dashboard |
| Try | primary problem; enters an idea or “cannot start.” | attempt event, item/version, timestamp | may acknowledge free text | opens attempt, validates input | encourage attempt; “cannot start” is valid |
| Get help | chooses a fixed hint. | immutable intervention ID/version/exposure time; pre-help attempt | optionally phrases selected feedback | delivers reviewed hint/logs exposure | hint is legitimate; no penalty |
| Solve | submits answer/method. | assisted-solve result/scoring version | optional explanation feedback | exact/symbolic score and state transition | correct: continue to new situation; incorrect: retry/review action |
| Use elsewhere | distinct Transfer Quest screen: changed representation, no solution context. | isolated task/session, condition, response, result | optional explanation feedback only | selects reviewed pair; prevents answer reveal; scores | pass/fail is about this task, never identity |
| Reveal connection | after response, sees “both use relation X.” | reveal event optional | short natural-language explanation | maps pair metadata to explanation | makes the changed representation meaningful |
| Receipt | pass produces Capability Receipt; history/progress changes. | receipt/evidence event; derived summary | none required | enforces receipt rule from actual events | shows demonstrated and unknown conditions |
| Recover | failure gives one useful next action; capability remains open. | contradictory event | may phrase recovery | chooses fixed recovery/retry route | “not stable in a new representation yet,” never rank loss |
| Return | Home shows historical Memory Return with timestamp. | seeded historical event, labelled | none | renders labelled history | no implication it happened live |

## Signature interaction

**The moment judges should remember:** a learner has just used legitimate help, then sees a problem that looks different enough to require recognition, applies the same mathematical tool in an isolated challenge, and receives a receipt that precisely distinguishes what was demonstrated from what remains unknown.

It is better than “another quiz” only if three visible facts occur without narration:

1. the help exposure is a concrete reviewed intervention, not a vague level;
2. the new task is visibly a changed representation and is isolated from the prior solution;
3. the receipt states conditions/provenance rather than an opaque score.

If the relation shift cannot be understood visually in seconds, choose a different micro-skill/pair. Do not compensate with a longer explanation.
