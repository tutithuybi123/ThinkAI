# THINKAI KIDS — Product Specification [DRAFT / PRE-FLIGHT DISCOVERY]

> [!IMPORTANT]
> **Status**: DRAFT / PRE-FLIGHT DISCOVERY.
> Product scope, target features, and UI flows are currently candidate proposals undergoing evaluation. Nothing in this document represents a final implementation commitment.

---

## 1. Product Purpose (Candidate Concept)

THINKAI KIDS is an AI-powered interactive learning and reasoning assistant designed for kids and students. It aims to provide guided problem solving, step-by-step hints, interactive exercises, and safe content moderation.

---

## 2. Candidate Scope for Evaluation

- [ ] **Interactive Chat / Query Interface**: Candidate guided learning interface.
- [ ] **Step-by-Step AI Tutor / Hint Pipeline**: Candidate structured hint generation model.
- [ ] **Safety & Moderation Guardrails**: Candidate content safety filter.
- [ ] **Progress Tracking Baseline**: Candidate session tracking model.

---

## 3. Candidate Non-Goals

- Multi-tenant school/district administration dashboards.
- Real-time video/audio streaming integration.
- Custom hardware integration.
- Paid subscription / payment gateway integrations.

---

## 4. Terminology

- **Learner / Kid**: Primary user interacting with the AI tutoring interface.
- **Hint Engine**: AI subsystem under evaluation for scaffolding hints.
- **Safety Guardrail**: Filter and prompt guard under evaluation.
