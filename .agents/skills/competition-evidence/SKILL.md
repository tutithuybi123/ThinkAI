# Competition Evidence

Use this skill whenever work introduces an external dependency, service, source, or AI-assisted configuration.

- Update the applicable tooling/source manifest with factual source, version or commit when known, installation date, purpose, classification, and configuration location.
- Preserve automatic Prompt Log coverage. Never fabricate, paraphrase, or backdate historical prompts; correct records append-only.
- Clearly distinguish team-built work, AI-assisted work, and inherited or external material.
- Never record credentials, secrets, or private child/student data. Keep any raw private evidence under `evidence/private/`.
- Keep citations and source references specific enough to trace the material actually used.

Follow the repository's existing AGENTS.md and evidence rules; this skill is a focused reminder, not a replacement for them.
